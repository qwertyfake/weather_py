## Описание программы

Weather Diary — GUI-приложение на Python с использованием Tkinter.

Функции программы:

- Добавление записей о погоде
- Просмотр записей
- Фильтрация по дате
- Фильтрация по температуре
- Сохранение в JSON
- Загрузка из JSON

---

## Как запустить

### 1. Установите Python

Скачать Python:

https://www.python.org

---

### 2. Клонируйте проект

```bash
git clone https://github.com/ВАШ_USERNAME/weather-diary.git
```

---

### 3. Перейдите в папку проекта

```bash
cd weather-diary
```

---

### 4. Запустите приложение

```bash
python main.py
```
